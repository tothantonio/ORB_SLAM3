## Instalare

```
git clone https://github.com/tothantonio/ORB_SLAM3.git
cd ORB_SLAM3
chmod +x build_prerequisites.sh
./build_prerequisites.sh

```

## Rebuild (dupa modificari cod)

```
chmod +x build.sh
./build.sh
```
